# Hansani Ekanayaka — Portfolio

## Folder structure

portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── profile.jpg
│   ├── homefixr.png
│   ├── farmhouse.png
│   ├── lseg-visit.jpg
│   └── codimite-visit.jpg
└── documents/
    └── CV.pdf

## Images

Put your own images in the `images` folder using these exact filenames:

- profile.jpg → your main portrait
- homefixr.png → HomeFixr screenshot
- farmhouse.png → Farmhouse project screenshot
- lseg-visit.jpg → LSEG industry visit photo
- codimite-visit.jpg → Codimite industry visit photo

If your images have different names, either rename them to the names above or change the matching `src="images/..."` line in index.html.

## CV

When you create your CV, save it as:

documents/CV.pdf

Then the Download CV button can be added/activated.

## Run locally

Open `index.html` in a browser, or use VS Code + Live Server.

## Deploy to Vercel

Upload this project to a GitHub repository, then import that repository into Vercel. No build command is required because this is a static HTML/CSS/JS website.
